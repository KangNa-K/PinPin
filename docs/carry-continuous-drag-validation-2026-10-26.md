# 连续吸图拖放验证（2026-10-26）

## 当前行为

- 自动吸图保留原始按压流；截图期间只将球设为透明，不通过 INVISIBLE 取消原始触摸窗口。
- 图片准备期间继续记录位移与松手/取消/第二指；图片就绪后同一根手指可直接触发系统拖放，不要求重新 ACTION_DOWN。
- 已松手或取消时不自动拖放、不误打开菜单；保留图片供下一次拖动。
- 只有系统 ACTION_DRAG_ENDED.result=true 才自动清空持久化携带状态和缩略图；拒收或取消保留。
- 相册明确保存成功后清空，保存失败保留。截图历史及独立导出副本不随球内清空删除，接收方仍可读取导出 URI。

## 本轮实测

- Android 15 模拟器 pinpin-review-api35：19 项专项仪器测试通过。
- 覆盖原生窗口连续拖放（一次 DOWN）、成功清空、拒收保留、取消保留、导出副本在清空后仍可读取、松手/第二指发生于截图载入前、原有选区手势和相册像素/路径。
- 70 项单元测试通过；lintDebug、assembleDebug、assembleDebugAndroidTest 通过。
- 测试报告：app/build/outputs/androidTest-results/connected/；日志 /tmp/pinpin-continuous-final.log。

## 边界

- 仪器测试模拟截图文件就绪，未执行小红书页面的完整截图识别链路；接收测试窗口与发送方同 UID，不能替代跨应用 URI 授权实测。
- 未连接三星平板，One UI 8.5 的任务栏悬停切应用、三星相册与 Magpie 的跨应用导入尚未验收。
- 系统接收成功不代表目标应用完成持久化；目标应用不支持拖放时不能强制导入。
- 本轮仅修改本地源码并构建测试，没有修改版本号、覆盖已发布 1.1.0 或发布新版本。
